# Rohilla Dental Chaksu - AI Voice Receptionist

24/7 AI receptionist that talks to patients, books appointments & handles queries.

## Features
- Realtime Voice Conversation
- Automatic Appointment Booking
- Business-aware Logic
- Low-latency with LiveKit

## Tech
Python, Django, LiveKit, WebRTC

## Run
pip install -e .
python receptionist/agent.py
